# Trap Hunter Bot - ระบบแจ้งเตือนสัญญาณเทรดรายวัน (BTC + ทองคำ) เข้า Telegram

ระบบอัตโนมัติที่ทำงานบนคลาวด์ GitHub ฟรี ตรวจตลาดทุก 5 นาทีตลอด 24 ชม. ไม่ต้องเปิดคอมทิ้งไว้
หา "จังหวะกับดักกลับด้าน" (ราคาแทงหลอกกิน SL รายย่อยแล้วกลับตัว) แล้วยิงการ์ดสัญญาณครบทุกอย่างเข้า Telegram ส่วนตัว:
สินทรัพย์ / ประเภทไม้สั้น-ยาว / ทิศทาง / โซน Entry / SL / TP1-TP3 / เหตุผลภาษาไทยอ่านง่าย

อัตราการยิง: โหมดไม่จำกัดจำนวน - เจอจังหวะที่ผ่านเกณฑ์ครบทุกชั้นเมื่อไหร่ ไม่ว่าเวลาไหนก็ยิงทันที
(ระบบยังเสียบกันซ้ำไว้: จังหวะเดิมระดับเดิมจะไม่ถูกยิงซ้ำภายใน 2 ชม. เพราะหน้าต่างตรวจจับยังมองเห็นเทียนชุดเดิมอยู่)
บางวันตลาดเงียบจริงจึงไม่มีสัญญาณเลย ซึ่งเป็นพฤติกรรมตามดีไซน์ ไม่ใช่ระบบพัง

ระบบมี "ความฉลาดปรับตัว": วัดสภาพตลาดทุกรอบสแกน (เงียบ / ปกติ / ผันผวนแรง)
แล้วปรับเกณฑ์กรองให้พอดีอัตโนมัติ - ดูรายละเอียดในหัวข้อ "ความฉลาดปรับตัวตามสภาพตลาด" ด้านล่าง

## คู่มือประกอบร่างฉบับ "กดคลิกทีละขั้น" (ใช้เวลาราว 20 นาที)

### ก่อนเริ่ม ต้องมีอะไรบ้าง

- บัญชี Google (Gmail) อันเดิมที่ใช้อยู่ก็ได้
- แอป Telegram บนมือถือ (สมัครฟรี ถ้ายังไม่มี)
- เครดิต OpenRouter ที่คุณมีอยู่แล้ว
- ไม่ต้องมีความรู้เขียนโค้ดเลย - ทุกขั้นคือกดคลิกและคัดลอก-วางเท่านั้น

---

### ขั้นที่ 1: สร้างบอท Telegram ของตัวเอง (5 นาที)

1. เปิดแอป Telegram ค้นหา `@BotFather` (ตัวอักษรเรียงตัวใหญ่ มีเครื่องหมายถูกสีฟ้า ยืนยันตัวจริง)
2. พิมพ์ `/newbot` แล้วส่ง
3. BotFather จะถามชื่อบอท พิมพ์ชื่อที่ชอบ เช่น `Trap Hunter ของฉัน`
4. ถาม username ต่อ ต้องลงท้ายด้วยคำว่า `bot` เช่น `mytrap_hunter_bot`
5. เสร็จแล้ว BotFather จะให้ข้อความยาวๆ หนึ่งชุด ลักษณะประมาณ
   `1234567890:AAHfj3k...` - นี่คือ **TOKEN** กดคัดลอกเก็บไว้ในโน้ต (ห้ามส่งให้ใคร)

### ขั้นที่ 2: หาเลข Chat ID ของคุณ + ปลุกบอท (2 นาที)

1. ค้นหา `@userinfobot` ใน Telegram กด Start มันจะตอบกลับมาเป็นตัวเลขชุดหนึ่ง เช่น `987654321`
   - นี่คือ **CHAT ID** คัดลอกเก็บไว้ในโน้ตด้วย
2. สำคัญมาก: กดเข้าไปคุยกับบอทที่สร้างไว้ในขั้นที่ 1 แล้วกดปุ่ม **Start** หนึ่งครั้ง
   (ถ้าไม่กด Telegram ไม่อนุญาตให้บอทส่งข้อความหาคุณ ระบบจะส่งสัญญาณไม่ถึงมือ)

### ขั้นที่ 3: สร้าง API Key ของ OpenRouter (2 นาที)

1. เปิดเว็บ `openrouter.ai/keys` แล้วล็อกอินด้วยบัญชีที่มีเครดิตอยู่
2. กดปุ่ม **Create Key** ตั้งชื่ออะไรก็ได้ เช่น `traphunter`
3. ระบบจะแสดง key ยาวๆ ขึ้นครั้งเดียว ลักษณะ `sk-or-v1-...` กดคัดลอกเก็บในโน้ต
   (คัดลอกตอนนี้เลย ปิดหน้าจอแล้วจะดูไม่ได้อีก ต้องสร้างใหม่)

### ขั้นที่ 4: เอาโค้ดขึ้น GitHub (8 นาที)

หมายเหตุสำคัญ: ถ้าผู้ช่วย AI สร้าง repository `trap-hunter-bot` และอัปโหลดโค้ดทั้งหมดให้ไปแล้ว
(เช็คได้ที่หน้า repo ถ้าเห็นไฟล์เรียงรายอยู่แล้ว = ข้ามขั้นที่ 4 ไปขั้นที่ 5 ได้ทันที)
ส่วนนี้เก็บไว้สำหรับกรณีจะประกอบร่างเองตั้งแต่ต้นหรือย้ายบัญชี

1. เปิดเว็บ `github.com` สมัคร/ล็อกอิน (ถ้ายังไม่มีบัญชี กด Sign up ใช้อีเมล Gmail ได้เลย)
2. กดเครื่องหมาย **+** มุมขวาบน แล้วเลือก **New repository**
3. ตั้งค่าหน้านี้ดังนี้:
   - Repository name: `trap-hunter-bot`
   - เลือก **Public** (แผนฟรีให้ Actions วิ่งไม่จำกัดนาทีบน Public repo - และปลอดภัยเพราะไฟล์โค้ดไม่มีคีย์ฝังอยู่ คีย์ทุกตัวเก็บในตู้เซฟ Secrets ตามขั้นที่ 5)
   - อย่าติ๊ก "Add a README file" ปล่อยว่างไว้ตามที่ระบบแนะนำ
   - กดปุ่มสีเขียว **Create repository**
4. หน้าถัดไปจะมีลิงก์ข้อความว่า "uploading an existing file" กดเข้าไป
5. แตกไฟล์ `trap-hunter-bot.zip` ที่ได้มาไว้บนเครื่องก่อน (คลิกขวา > Extract All / แตกไฟล์)
6. เปิดโฟลเดอร์ `trap-hunter-bot` ที่แตกออกมา **เลือกของข้างในทั้งหมด** แล้วลากทิ้งลงพื้นที่อัปโหลดบนเว็บ:
   - ของข้างในคือ: โฟลเดอร์ `trapbot`, โฟลเดอร์ `state`, โฟลเดอร์ `.github`,
     ไฟล์ `main.py`, `backtest_scan.py`, `config.yaml`, `requirements.txt`, `README.md`, `_WORKFLOW_BACKUP.md`
   - Windows: มองเห็นโฟลเดอร์ `.github` ได้ปกติ
   - macOS: โฟลเดอร์ `.github` ถูกซ่อนไว้ ให้กด `Cmd + Shift + .` ในหน้าต่าง Finder ก่อน แล้วมันจะโผล่มา
7. รอจนหน้าเว็บขึ้นว่าอัปโหลดครบ แล้วกดปุ่ม **Commit changes**
8. **เช็คพรมแดน (ข้อบังคับ):** หน้าแรกของ repo ต้องเห็นรายการประมาณนี้ โดยไฟล์ต้องอยู่ "นอก" โฟลเดอร์ ไม่ได้ซ้อนอยู่ในโฟลเดอร์อีกที:
   ```
   .github      main.py   backtest_scan.py   config.yaml
   requirements.txt   README.md   _WORKFLOW_BACKUP.md   state   trapbot
   ```
   - ถ้าไม่เห็นโฟลเดอร์ `.github` = อัปโหลดไม่ครบ ให้ทำ "ทางลัดกู้สถานการณ์" ท้ายเล่มนี้
   - ถ้าเห็นไฟล์ซ้อนอยู่ในโฟลเดอร์ trap-hunter-bot อีกชั้น = ลากผิดชั้น ลบแล้วอัปโหลดใหม่โดยเลือก "ของข้างใน"

### ขั้นที่ 5: ฝากคีย์ 3 ตัวไว้กับ GitHub (3 นาที)

GitHub มีตู้เซฟสำหรับคีย์ชื่อ Secrets - คีย์จะไม่ถูกเขียนลงโค้ดและไม่มีใครมองเห็น

1. ในหน้า repo กดที่แท็บ **Settings** (ฟันเฟือง)
2. เมนูซ้ายมือ: **Secrets and variables > Actions**
3. กดปุ่ม **New repository secret** แล้วสร้างทีละตัวทั้ง 3 ตัว (คัดลอกจากโน้ตของคุณ):

   | ช่อง Name | ช่อง Secret (ค่าที่วาง) |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | token ยาวๆ จากขั้นที่ 1 |
   | `TELEGRAM_CHAT_ID` | ตัวเลข chat id จากขั้นที่ 2 |
   | `OPENROUTER_API_KEY` | key ยาวๆ `sk-or-v1-...` จากขั้นที่ 3 |

   (พิมพ์ชื่อในช่อง Name ให้ตรงเป๊ะ ตัวใหญ่ตัวเล็กและขีดล่าง ไม่มีเว้นวรรค)

### ขั้นที่ 6: จุดระเบิดนัดแรก - ทดสอบยิงจริง (2 นาที)

1. กลับหน้าแรก repo กดแท็บ **Actions**
2. เมนูซ้ายจะมี **signal-scan** กดเข้าไป
3. ขวาบนมีปุ่ม **Run workflow** กด แล้วกดปุ่มสีเขียว **Run workflow** อีกครั้ง
4. รอสักคู่ รายการจะโผล่มา กดเข้าไปดูได้ว่ามันกำลังทำอะไร (สถานะสีเขียว = ทำงานสำเร็จ)
5. หมายเหตุ: รอบทดสอบนี้จะไม่มีข้อความเข้า Telegram ก็เป็นเรื่องปกติเพราะระบบส่งเฉพาะ
   ตอนตลาดมีจังหวะจริง (ไม่จำกัดจำนวน แต่ต้องผ่านเกณฑ์ครบ) ถ้าสถานะเป็นสีเขียว = ปืนพร้อมยิงแล้ว
   และถ้ายังไม่ได้ใส่คีย์ Telegram ระบบจะ "พิมพ์การ์ดสัญญาณไว้ใน log" แทนการส่ง สถานะยังเขียว ไม่พัง
   อยากดูว่าตอนนี้ระบบมองตลาดเป็นอย่างไร ให้กดเข้า run ล่าสุด > กดที่ขั้น "Scan market and send signals"
   จะเห็นบันทึกภาษาไทย: สภาพตลาดตอนนี้ (เงียบ/ปกติ/ผันผวนแรง) และรอบนี้มีจังหวะหรือไม่

### ขั้นที่ 7: เสร็จสิ้น - ระบบทำงานเองตลอดไป

- ตั้งแต่ตอนนี้ GitHub จะยิงระบบให้สแกนตลาดทุก 5 นาที ตลอด 24 ชม. เองอัตโนมัติ
- มีจังหวะผ่านครบทุกชั้นยืนยัน = การ์ดสัญญาณครบ Entry/SL/TP1-TP3/เหตุผลไทย จะเด้งเข้า Telegram ทันที
- AI (ผ่าน OpenRouter) จะตื่นมาตรวจซ้ำ + เขียนเหตุผลให้ลื่นขึ้น เฉพาะตอนมีสัญญาณเท่านั้น
  จึงกินเครดิตน้อยมาก (ประมาณไม่กี่เซนต์ต่อเดือน) - วันที่ไม่มีสัญญาณ = ไม่เรียก AI เลย

## ทางลัดกู้สถานการณ์: อัปโหลดแล้วไม่เห็นโฟลเดอร์ .github

โฟลเดอร์ที่ชื่อขึ้นต้นด้วยจุดถูกซ่อนในบางเครื่อง ถ้าขั้นที่ 4 เช็คแล้วไม่มี `.github` ให้สร้างมือแทน:

1. ในหน้า repo กด **Add file > Create new file**
2. พิมพ์ชื่อว่า `.github/workflows/signal.yml` - พอพิมพ์เครื่องหมาย `/` GitHub จะสร้างโฟลเดอร์ให้เอง
3. เปิดไฟล์ `_WORKFLOW_BACKUP.md` ใน repo (ไฟล์สำรองที่แถมมากับชุดนี้) คัดลอกเนื้อหา
   ช่วงล่างทั้งหมด (ตรงกรอบเส้นประลงมา) วางลงช่องแก้ไขไฟล์
4. กด **Commit changes** เป็นอันเรียบร้อย แล้วลบ `_WORKFLOW_BACKUP.md` ทิ้งได้

## ความฉลาดปรับตัวตามสภาพตลาด (Market Regime Adaptation)

กติกาค่าคงที่หนึ่งชุด ใช้กับตลาดสองสภาพไม่ได้ - ระบบจึงวัดสภาพตลาดทุกรอบสแกน
ด้วยวิธีโปร่งใส: เทียบ ATR(14) บนกราฟ 1 ชม. "ตอนนี้" กับค่ามัธยฐานย้อนหลัง 100 แท่งของตัวเอง
(ไม่เรียก AI เพิ่ม ไม่มีต้นทุน คำนวณจากราคาจริง) แล้วปรับเกณฑ์ให้พอดีอัตโนมัติ:

| สภาพตลาด | เงื่อนไข (ATR ตอนนี้ เทียบค่ากลาง) | สิ่งที่ระบบปรับให้อัตโนมัติ |
|---|---|---|
| เงียบ (QUIET) | ต่ำกว่า 0.70 เท่า | คลายเกณฑ์วอลลุ่ม/ไส้เทียนลงเล็กน้อย + ลดเป้าขั้นต่ำ 1.5R -> 1.2R ให้สมดุลกับราคาที่เดินแคบ |
| ปกติ (NORMAL) | 0.70 - 1.50 เท่า | ใช้ค่าพื้นฐานตาม config เดิม |
| ผันผวนแรง (VOLATILE) | สูงกว่า 1.50 เท่า | ยกเกณฑ์ทุกชั้น: วอลลุ่มต้องหนักกว่า (1.8 -> 2.2 เท่า), ไส้ต้องยาวกว่า, เป้าขั้นต่ำ 1.5R -> 1.8R, SL ห่างไส้มากขึ้น (กันตลาดพาดลึก), และยกเพดานกรอง "เทียนยักษ์จากข่าว" ขึ้น |

ผลลัพธ์ที่ได้: ช่วงตลาดสั่นแรง (ข่าวใหญ่) ระบบเข้มกรองขึ้นเพื่อหยิบเฉพาะของจริงและวางจุดกันชนกว้างขึ้น
ส่วนช่วงตลาดเงียบ ระบบคลายให้ยังจับจังหวะได้แบบสมดุล - ไม่ต้องมานั่งแก้ config เองตามช่วงเวลา
การ์ดสัญญาณจะบอกสภาพตลาดตอนนั้นมาด้วยทุกไม้ และเหตุผลจะอธิบายว่าระบบปรับเกณฑ์อย่างไร

> ต้องการกลับไปใช้ค่าคงที่ตลอดกาล? ตั้ง `regime.enabled: false` ใน config.yaml ได้เลย

## ทดสอบย้อนหลังก่อนใช้เงินจริง (แนะนำอย่างยิ่ง)

```bash
python backtest_scan.py --asset BTCUSDT --days 45
python backtest_scan.py --asset XAUUSD --days 45
```
ระบบจะจำลองว่าถ้ารันอยู่ตอนนั้นจะยิงไม้อะไร พร้อมผลจำลองตามแผนเก็บกำไร 30/40/30
(ส่วนนี้ต้องพิมพ์คำสั่งในเครื่องตัวเองเท่านั้น ไม่จำเป็นต้องทำเพื่อให้ระบบยิงสัญญาณได้)

## ทางเลือก: รันบนคอมตัวเอง (ไม่ใช้ GitHub)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="...โทเคน..."
export TELEGRAM_CHAT_ID="...ไอดีแชท..."
export OPENROUTER_API_KEY="...คีย์ OpenRouter..."   # ไม่ใส่ก็รันได้ ใช้เทมเพลตเหตุผลแทน
python main.py --dry-run    # พิมพ์การ์ดออกจอ ไม่ยิงจริง - ใช้ทดสอบก่อนได้
python main.py              # รันจริง (ใช้ cron ทุก 5 นาที: */5 * * * * python main.py)
```

## ปรับแต่งพฤติกรรม (config.yaml)

| ค่า | ผลของการปรับ |
|---|---|
| `volume_mult` (1.8) | ค่าพื้นฐานช่วงตลาดปกติ - ช่วงผันผวนแรงระบบจะยกเป็น 2.2 / ช่วงเงียบลดเป็น 1.5 ให้เอง |
| `reclaim_window` (3) | ลดเหลือ 2 = ยอมรับเฉพาะกลับตัวเร็วพิเศษ |
| `min_rr_tp2` (1.5) | ค่าพื้นฐาน - ระบบปรับเป็น 1.2 (เงียบ) / 1.8 (ผันผวนแรง) ให้เอง |
| `cooldown_hours` (2) | กันยิงซ้ำ "จังหวะเดิม" - ไม่ใช่การจำกัดจำนวน จังหวะใหม่ระดับอื่นยิงได้ทันที |
| `max_signals_per_day` (999) | โหมดไม่จำกัด - ลดเป็นเลขอื่นได้ถ้าอยากคุมจำนวนสูงสุดต่อวัน |
| `regime.enabled` (true) | ปิดได้ถ้าอยากใช้ค่าคงที่หนึ่งชุดตลอดกาล (ไม่แนะนำ) |
| `allow_counter_trend` (false) | เปิด true = ยอมเสี่ยงแทงกับดักสวนกราฟใหญ่ (ไม่แนะนำสำหรับมือใหม่) |
| `ai.model` (openai/gpt-4o-mini) | เปลี่ยนโมเดลบน OpenRouter ได้อิสระ เช่นโมเดลฟรีที่ระบุไว้ในคอมเมนต์ |

## ข้อจำกัดที่ควรรู้ก่อนใช้จริง

- ราคาทองมาจากฟิวเจอร์ส COMEX ตัวเลขจะต่างจาก spot XAUUSD ที่เทรดจริงราว 0.5-1 ดอลลาร์
  ให้ใช้ "จังหวะและโครงสร้าง" แล้วแปลงโซนราคาเทียบกับโบรกของคุณเอง
- cron ของ GitHub Actions อาจเริ่มงานช้ากว่าตาราง 1-3 นาทีในช่วงคนใช้เยอะ - ไม่กระทบสัญญาณ 15m
- workflow ฟรีจะหยุดถ้า repo เงียบ 60 วัน (ดูตารางบำรุงรักษาด้านบน)
- ข้อมูลทองฝั่งฟรีไม่มี "แรงซื้อ-ขายสุทธิ" ระบบจึงใช้กฎกลับตัวเร็วพิเศษ (ภายใน 2 แท่ง) ทดแทน
- ถ้าไม่ใส่ OPENROUTER_API_KEY ระบบยังยิงสัญญาณได้ปกติ เพียงแต่เหตุผลเป็นเทมเพลตมาตรฐาน
  และถ้า OpenRouter ล่มชั่วคราว ระบบจะหันไปใช้เทมเพลตเองอัตโนมัติ - สัญญาณไม่หายแน่นอน

## ข้อความเตือนสำคัญ

ระบบนี้เป็นเครื่องมือวิเคราะห์และแจ้งเตือน ไม่ใช่คำรับประกันกำไร
ไม่มีระบบใดแม่นยำ 100% จังหวะที่ดูดีที่สุดก็พลาดได้ ทดสอบย้อนหลังและใช้งานจริงบน
กระดาษ (ไม่ใส่เงิน) อย่างน้อย 2-4 สัปดาห์ ก่อนตัดสินใจใช้เงินจริง และคุมความเสี่ยง
ไม่เกิน 1% ของพอร์ตต่อไม้เสมอ การเทรด BTC และทองคำมีความผันผวนสูง ศึกษาและรับผิดชอบความเสี่ยงเอง
